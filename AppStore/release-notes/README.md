# What's New for updates

Existing descriptions, review notes and common fields stay in
`AppStore/app-store-metadata.md`. Do not copy them here.

For an update after the first public release, add:

```text
AppStore/release-notes/<MARKETING_VERSION>/en-US.txt
AppStore/release-notes/<MARKETING_VERSION>/ru-RU.txt
```

Use truthful public release notes, plain UTF-8 text, 1–4000 characters.
The initial release needs no What's New. Missing optional files never clear remote
values; an update without local or existing server notes stops with a diagnostic.
